**Subtitle:** Autonomous Edge-AI Operating System for Extra-Planetary Bio-Regenerative Life Support Systems.

## 🚀 Executive Summary
MARS-ROOTS is a specialized software architecture designed to manage greenhouse environments and habitat resources on Mars. Built on **First Principles**, the system prioritizes survival under extreme resource scarcity and handles the 22-minute communication latency through a decentralized **Edge-AI engine**.

## 🧠 Key Technical Features
*   **Latency-Independent Master OS:** A centralized decision engine that manages habitat safety, power-grid synergy, and emergency protocols (e.g., solar flares and dust storms) locally.
*   **Climate-Adaptive Irrigation:** An advanced logic that calculates precise water delivery by cross-referencing soil moisture, plant stress, and *evaporation rates* based on temperature.
*   **Autonomous Reconnaissance:** Support for the **ARES-1 Scout Drone**, performing automated terrain scanning to locate Water Ice and Iron Ore.
*   **Power-Grid Synergy:** Dynamically scales life support based on solar flux data, ensuring survival during Martian dust storms.
*   **Mission Logging:** A persistent logging system (`mission_log.txt`) that records all AI decisions for the crew.

## 📂 Project Structure
- **`master_os.py`**: The NEW "Brain" of the base. Integrated high-level survival logic.
- **`advanced_irrigation.py`**: The NEW precision agriculture module with temperature compensation.
- **`main_os.py`**: Legacy basic OS script (Initial Prototype from Day 1).
- **`irrigation_module.py`**: Legacy basic irrigation module (Initial Prototype from Day 1).
- **`mission_log.txt`**: (Auto-generated) Real-time data log of all AI decisions.
