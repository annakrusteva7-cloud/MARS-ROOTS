## 🚀 Executive Summary
MARS-ROOTS is a specialized software architecture designed to manage greenhouse environments and habitat resources on Mars. Built on **First Principles**, the system prioritizes survival under extreme resource scarcity and handles the 22-minute communication latency through a decentralized **Edge-AI engine**. This ensures the colony remains operational during solar events and dust storms without requiring real-time input from Earth.

## 🧠 Key Technical Features
*   **Latency-Independent Master OS (`master_os.py`):** A centralized decision engine that manages habitat safety, power-grid synergy, and emergency protocols (e.g., solar flares and dust storms) locally.
*   **Climate-Adaptive Irrigation (`advanced_irrigation.py`):** An advanced version of the irrigation logic that calculates precise water delivery by cross-referencing soil moisture, plant stress, and *evaporation rates* based on real-time ambient temperature.
*   **Autonomous Reconnaissance:** Integrated support for the **ARES-1 Scout Drone**, which performs automated terrain scanning to locate critical raw materials (Water Ice, Iron Ore) for base expansion.
*   **Power-Grid Synergy:** The software dynamically scales lighting and life support based on solar flux data and battery reserves, ensuring survival during Martian dust storms.
*   **Mission Logging & AI Feedback:** A persistent logging system (`mission_log.txt`) coupled with a simulated voice interface to provide the crew with actionable insights.

## 📂 Project Structure
- `master_os.py`: The "Brain" of the base. Handles high-level survival logic.
- `advanced_irrigation.py`: Precision agriculture module with temperature compensation.
- `irrigation_logic_v1.py`: Legacy basic irrigation script (Initial Prototype from Day 1).
- `mission_log.txt`: Real-time data log of all AI decisions and sensor events.

## 🛠 Technical Stack
*   **Language:** Python 3.10+
*   **Logic:** Heuristic Edge-AI & Predictive Resource Modeling.
*   **Architecture:** Modular Microservices (allowing independent updates to drone or life-support modules).
